## Условие
# Самолёт летит по прямой на высоте H метров со скоростью Vc м/c в направлении зенитной пусковой установки. Когда до неё остаётся S метров по нему выпускается ракета со скоростью Vp. Считая, что до места встречи ракета летит по прямой и радиус её бесконечен, определить T - время до поражения цели
# 1. Алгоритм и блок-схема
## Алгоритм
1. Начало 
2. Объявить переменные:
* H - Высота, S - Расстояние, Vp - Скорость, T - Время
3. Вычислить значение по формуле:
* T = √(S² + H²) / Vp
4. Вывести полученный результат.
